# Abdullah Fekry — Portfolio

A personal portfolio for Abdullah Fekry, an independent developer building thoughtful digital experiences.

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
```

The production files are written to `dist/public`.

## Customize

Most portfolio copy and project information lives in `src/App.tsx`. Visual tokens, typography, motion, and responsive styles live in `src/index.css`.
